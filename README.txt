쯔꾸르(RPG Maker MV/MZ) 게임 한국어화 도구
==========================================

[고지]
이 도구는 사용자가 이미 합법적으로 소유한 게임 파일을 본인 컴퓨터에서
로컬로 처리(복사·번역·패치)하기 위한 것입니다. 게임 파일이나 번역
결과물을 다운로드/호스팅/배포하지 않으며, 이 저장소에는 어떠한 게임
콘텐츠도 포함되어 있지 않습니다. 이 도구로 만든 번역본을 배포하는 것은
원작 게임의 저작권자 정책에 따라 별도로 허용 여부가 갈릴 수 있으니,
배포 전 확인은 사용자 책임입니다.

[서드파티 라이선스]
plugins/MV, MZ 폴더의 SteamB23_HangulNameEdit.js는 SteamB23님이 만든
MIT 라이선스 플러그인입니다 (Copyright (c) 2016 SteamB23). 전체 라이선스
전문은 각 파일 안에 포함되어 있습니다.

[사용법]
1. 쯔꾸르_한국어화_도구.exe 더블클릭
2. 원본 게임 폴더 / 출력 폴더 / 한국어 폰트(기본값: 맑은 고딕) 선택
3. 번역 방식 고르기
   - API 우선 + 로컬 보완 (기본): API로 빠르게 먼저 번역하고, 결과를 자동
     검사해서 문제 있는 것만 로컬 모델(Ollama)이 다시 번역합니다.
   - API만: Ollama 없이 API로만. API가 못 한 문장은 원문 그대로 두고
     "검토 항목 보기"에 "번역 안 됨"으로 올라옵니다.
   - 로컬만: 예전처럼 전부 Ollama로.
   자동 검사가 걸러내는 것: 제어 코드(\N[1] 등) 손상, 한글 없음, 일본어가
   남음, 다른 언어가 섞임, API가 번역 대신 거절/설명한 응답.
   (어색한 번역까지 기계가 다 알아낼 수는 없어요 -- 그건 검토 창에서.)
4. API 엔진 고르기 + "API 설정..."에서 키/모델 입력 후 "연결 테스트" -> "저장"
   - 구글 번역 (무료, 키 없음): 설정 없이 바로. 비공식 경로라 많이 돌리면
     구글이 한동안 막을 수 있습니다 (막히면 자동으로 API를 끄고 로컬로 넘어감).
   - Google Cloud 번역 (공식 키): 키에 'HTTP 리퍼러' 제한이 있으면 안 됩니다.
   - DeepL: 무료 키(끝이 ':fx')는 월 50만 자까지.
   - OpenAI 호환: OpenAI, OpenRouter, LM Studio 등. 주소는 .../v1 까지.
   - Claude: 기본 모델 claude-opus-5. 거절된 묶음은 Anthropic 서버에서 다른
     Claude 모델이 이어받는 기능(server-side fallback)을 켜 두었습니다.
   - Gemini: 모델 이름을 AI Studio 목록에 있는 그대로 입력.
   성인향 대사처럼 API가 거절하는 문장은 "API 우선 + 로컬 보완"에서
   자동으로 로컬 모델이 번역합니다.
   API 키는 %APPDATA%\쯔꾸르_한국어화_도구\settings.json 에 Windows 계정
   기준으로 암호화(DPAPI)되어 저장됩니다. 다른 PC나 다른 Windows 계정에서는
   풀 수 없고, 게임 폴더/출력 폴더/저장소에는 절대 저장되지 않습니다.
5. 로컬 모델 확인 (드롭다운에서 설치된 Ollama 모델 자동으로 나옴)
6. (선택) "용어집 확인/수정" 으로 캐릭터명 등 고유명사를 미리 확인·수정
   - 원본 게임 폴더 / 출력 폴더 / 번역 모델을 먼저 지정해야 열립니다.
   - 여기서 직접 입력하거나 "번역 받기"로 AI 제안을 받아 저장하면,
     본 번역 실행 시 그 값을 그대로 사용합니다.
   - LLM 계열 API(OpenAI 호환, Claude, Gemini)에도 용어집이 전달됩니다.
     구글/DeepL 같은 일반 번역 API는 용어집을 못 받습니다.
7. "번역 시작" 클릭
   - "이름 입력창 한글 지원 플러그인 추가" 체크박스(기본 켜짐): 게임에
     이름 입력 씬이 있으면 한글로 이름을 지을 수 있게 플러그인을 자동
     설치합니다. 필요 없으면 체크 해제하세요.
   - "완료 후 자동 종료" 체크박스(기본 꺼짐): 번역이 끝났을 때 검토가
     필요한 항목이 하나도 없으면 Ollama를 끄고 60초 후 PC를 종료합니다
     (자는 동안 돌려놓고 싶을 때 사용). 검토 항목이 하나라도 있으면
     평소처럼 켜진 채로 두고 종료하지 않습니다. Windows 알림에서 60초
     안에 취소할 수도 있습니다.
   - "완료 후 알림" 체크박스(기본 꺼짐): 번역이 끝나면 Windows 알림
     (토스트) + 소리로 완료를 알려줍니다. 검토가 필요한 항목이 없으면
     Ollama가 실제로 꺼진 걸 확인한 뒤 프로그램도 자동으로 닫습니다
     (PC는 끄지 않음 -- PC까지 끄려면 위의 "완료 후 자동 종료"를 쓰세요).
     Ollama가 반복 시도에도 안 꺼지면 억지로 닫지 않고 프로그램을 열어둔
     채 경고를 남깁니다. 검토 항목이 있으면 알림만 오고 프로그램은
     그대로 켜져 있습니다.
8. 완료 후 오역 의심 항목이 있으면 "검토 항목 보기" 로 확인·수정
   ("재번역" 버튼으로 AI에게 다시 시켜볼 수도 있음)


[다른 컴퓨터에서 처음 쓸 때]

가장 쉬운 방법: 처음_설치.bat 더블클릭
   - Ollama가 없으면 winget으로 자동 설치, 있으면 건너뜀
   - 번역 모델을 확인해서 없을 때만 다운로드 (약 8.4GB)
   - 동시 번역 처리량 환경변수까지 자동 설정
   - winget이 없는 환경이면 아래 수동 설치 안내로 넘어갑니다
   - 쯔꾸르_한국어화_도구.exe가 없으면(예: GitHub에서 소스만 받은 경우)
     Python이 설치되어 있을 때 자동으로 소스에서 빌드합니다. Python이
     없으면 설치 안내가 나옵니다 (https://python.org, 설치 시 "Add
     python.exe to PATH" 체크 필요).

수동으로 하려면:

1. Ollama 설치
   https://ollama.com 에서 다운로드 설치, 또는:
   winget install Ollama.Ollama

2. 번역 모델 받기 (택 1, 터미널/명령 프롬프트에서 실행)

   추천 - 게임 번역 전용 파인튜닝 모델 (약 8.4GB):
   ollama run hf.co/hell0ks/ja-ko-vn-12b-v2-gguf:Q5_K_M
   (위 모델을 사용할 경우 Temperature: 0.1, Top_k = 0.95, repetition_penalty 1.05 ~ 1.1를 추천)

   또는 범용 모델 (약 9GB):
   ollama pull qwen2.5:14b-instruct

3. (선택, 권장) 동시 번역 요청 처리량을 올리려면 사용자 환경변수 설정:
   OLLAMA_NUM_PARALLEL = 4
   OLLAMA_CONTEXT_LENGTH = 4096
   설정 후 Ollama 재시작 필요 (프로그램 안의 "Ollama 중지" -> "Ollama 시작"
   버튼으로도 재시작 가능하지만, 새로 설정한 환경변수는 Windows 로그인을
   다시 하거나 새 터미널에서 설정해야 확실히 반영됨)

VRAM이 부족한 컴퓨터는 qwen2.5:7b-instruct 같은 더 작은 모델을 받아서
"로컬 모델 (Ollama)" 드롭다운에 직접 입력하면 됩니다.


[src 폴더]
프로그램 소스 코드(Python)입니다. 여기를 고쳐서 재빌드하면 exe가 갱신돼요.
필요 패키지: pip install pyinstaller fonttools brotli requests customtkinter anthropic

재빌드 명령어:
    cd src
    pyinstaller --noconfirm --onefile --windowed --name "쯔꾸르_한국어화_도구" ^
      --collect-all customtkinter --add-data "plugins;plugins" --distpath .. gui.py

이 위 exe 파일을 덮어써서 새로 만들어줍니다.

[src/tests 폴더]
자동화된 테스트(pytest)입니다. Ollama나 실제 게임 파일 없이 코드 로직만
검증해요 (텍스트 추출/치환, 번역 품질 체크, asar 압축 해제, 엔진 감지 등).
코드를 고친 뒤에는 항상 이걸 돌려서 기존 기능이 깨지지 않았는지 확인하세요.

    pip install pytest
    cd src
    pytest tests/ -v


[주의]
- 지금은 RPG Maker MV/MZ만 지원합니다 (VX Ace, 2000/2003 미지원)
- 이미지에 그려진 텍스트(타이틀 로고 등)는 번역 대상이 아닙니다.
  게임 데이터(JSON)에 저장된 대화문/선택지/아이템 설명/시스템 용어만 처리됩니다.
- 원본 게임 폴더는 건드리지 않고, 지정한 출력 폴더에 복사본을 만들어서 그쪽만 수정합니다.
- 번역 캐시(...`_translations.json`)가 출력 폴더의 부모 폴더에 저장되어서,
  중간에 껐다 다시 돌려도 이어서 번역됩니다. 각 번역이 어디서 왔는지
  (API 엔진 / 로컬 모델 / 직접 수정)도 함께 기록됩니다. 예전 형식의 캐시
  파일도 그대로 읽고, 다음 저장 때 새 형식으로 바뀝니다.
- API 번역은 해당 서비스로 게임 텍스트를 보냅니다. 로컬만 쓰면 아무것도
  밖으로 나가지 않습니다.
- 여러 줄 대사는 한 문단으로 합쳐서 번역합니다 (일본어 줄바꿈 위치에서 문장이
  잘린 채 번역되지 않도록). 넣을 때는 원래 줄 수에 맞춰 다시 나누고, 이벤트
  명령 개수는 절대 바꾸지 않습니다 -- 번역이 길어 줄이 남으면 마지막 줄에
  몰아넣고(메시지창이 다음 페이지로 넘김), 짧으면 남는 줄은 빈 줄이 됩니다.
  예전 버전에서 줄 단위로 번역해둔 캐시가 있으면 이어붙여서 재사용합니다.
- 게임이나 플러그인이 "이름으로 찾아 쓰는" 값(메모칸 태그 속 스킬/속성 이름,
  스크립트 안의 아이템 이름, 스위치·변수·애니메이션 이름, 플러그인 설정 값,
  플러그인 코드 안의 문자열 등)과 똑같은 텍스트는 데이터 파일에는 원문 그대로
  두고, 화면에 그릴 때만 한국어로 바꿔 보여줍니다. 번역 때문에 플러그인이 대상을
  못 찾아 게임이 깨지는 걸 막기 위해서입니다. 로그에 몇 개가 해당되는지와 예시가
  나옵니다. 대사 속 \N[1] 같은 코드로 들어가는 이름도 화면에서는 한국어로 나옵니다.
- 번역과 별개로, "이름 입력창 한글 지원 플러그인"(SteamB23_HangulNameEdit,
  MIT 라이선스)이 번역 시작 시 자동으로 게임에 추가됩니다. 이름 입력 씬이
  없는 게임에는 그냥 무해하게 아무 영향도 없습니다.


[처음_설치.bat 수정 시 주의 (개발자용)]
이 파일은 UTF-8이 아니라 CP949(한국어 Windows 기본 코드페이지)로,
줄바꿈은 CRLF로 저장되어 있어야 합니다. UTF-8로 저장하거나 LF 줄바꿈으로
저장하면 cmd.exe가 한글이 포함된 줄을 엉뚱하게 여러 명령으로 쪼개 실행하는
문제가 실제로 발생합니다 (둘 다 실기기에서 재현 확인됨). 수정 후에는:
    python -c "d=open('처음_설치.bat','rb').read(); assert b'\r\n' in d and d.decode('cp949')"
같은 식으로 CRLF와 CP949 디코딩이 둘 다 되는지 확인하고 저장하세요.
